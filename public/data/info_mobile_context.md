# Mobile · Tab „Kontext“

**RAG kurz:** Kontext sind Zusatzinformationen, die die Antwort gezielt steuern.

In diesem Demo wird Kontext über eine einfache **Kategorisierung** erzeugt:
- Frage wird einer oder mehreren Kategorien zugeordnet
- passende Textbausteine werden geladen

Im Tab **Kontext** können Sie den Inhalt prüfen, anpassen oder löschen.  
Schon kleine Änderungen können die Antwort deutlich verändern.
