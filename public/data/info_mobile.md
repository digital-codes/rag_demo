# RAG-Demonstrator (Mobile)

Kurzer Überblick: **RAG** kombiniert
- **Prompt** (Regeln),
- **Frage** (Input),
- **Kontext** (zusätzliche Infos),
damit die Antwort besser zur Aufgabe passt.

In der mobilen Ansicht gibt es drei Tabs:
- **Prompt**
- **Q&A**
- **Kontext**

Tippen Sie auf **Info**, um die Hilfe passend zum aktuell geöffneten Tab zu sehen.
