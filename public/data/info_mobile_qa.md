# Mobile · Tab „Q&A“

**RAG kurz:** Das Modell nutzt nicht nur Ihre Frage, sondern auch Prompt und Kontext.

Im Tab **Q&A**:
1. Frage eingeben
2. **Suche** starten (Kontext wird vorbereitet)
3. Antwort wird mit dem aktuellen Prompt erzeugt

Dieser Tab ist ideal, um Varianten zu testen:  
gleiche Frage, aber anderer Prompt oder geänderter Kontext.
