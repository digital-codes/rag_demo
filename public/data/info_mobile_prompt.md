# Mobile · Tab „Prompt“

**RAG kurz:** Antwort = Prompt + Frage + Kontext.

Im Tab **Prompt** legen Sie fest, wie das Modell antworten soll:
- Stil und Ton
- Genauigkeit und Fokus
- wichtige Regeln

Ändern Sie den Prompt und vergleichen Sie später die Antwort im Q&A-Tab.  
So sehen Sie direkt den Einfluss des System Promptings.
